Spike S3: browser callback to the CLI

Each link plays the company's authorization server, redirecting to the agent host's /oauth/callback with a test code. The callback page then forwards to the CLI listener on 127.0.0.1. Only test values are used, and nothing here is a real token.

    For each link, note what the browser does: a smooth redirect, a warning or permission prompt, an error page, or nothing. The listener records every hit it receives.
